개념 시각화 추천

두 학습자 비교

실제 동료 평가 때 켜 두는 화면입니다. 대화를 들으며 지금 이야기하는 개념의 시각화를 추천 카드로 띄우고, 피평가자의 지난 피드백에 맞춘 단계로 엽니다. 이 데모는 녹음 대신 글로 대화를 넣습니다.

  1. 피평가자 이름을 아무거나 넣습니다(예: 학습자A).
  2. 피드백 예시 채우기 → 피드백 분석을 누르면 개념별 상태가 칩으로 뜹니다. 건너뛰어도 됩니다.
  3. 녹음 동의 두 칸을 체크하고 평가 시작을 누릅니다.
  4. 대화 예시 버튼을 누르거나 직접 입력하면 오른쪽에 추천 카드가 쌓입니다. 카드를 누르면 가운데에 열립니다.

두 학습자를 나란히 비교하려면 위의 두 학습자 비교로 가세요.

평가 준비

지난 동료 평가 피드백 붙여넣기 (선택)

평가 화면의 피드백 글을 그대로 붙여넣으세요. 이름은 지우고, 개념별 상태만 저장합니다. 피드백 원문은 저장하지 않습니다.

녹음 동의

평가 내내 듣고, 받아 적은 뒤 녹음은 바로 지웁니다. 평가가 끝나면 다룬 개념만 기록합니다.
